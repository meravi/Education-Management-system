# Security Policy

If you discover a security vulnerability in this project, please privately contact us at:

**Email:** khadkaravi170@gmail.com

We take all security issues seriously and will respond as soon as possible.

## Supported Versions

We generally support the latest stable release. Please report vulnerabilities as soon as they are discovered.

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities. Instead, email us directly and provide as much detail as possible so that we can address the issue promptly.
